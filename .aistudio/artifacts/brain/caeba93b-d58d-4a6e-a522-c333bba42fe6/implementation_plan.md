## Verified Facts & System Evidence

3. **Orphaned Root Assets**:
   - `bun.lock`: Leftover Bun lockfile in an npm-managed environment.
   - `worker.ts` & `wrangler.toml`: Cloudflare Workers deployment code duplicating `server.ts`.
   - `.gitignore`: Missing `dev-dist/` generated by `@vite-plugin-pwa`.
4. **Unreferenced / Semi-Integrated Code**:
   - `src/mobile/utils/sortRepos.ts` (87 LOC): Full deterministic multi-dimensional repository filtering (type, language, search) and sorting (stars, forks, name, updated) created but not currently called by `useRepositoriesState.ts`.
   - `src/features/clone/utils/cloneService.ts` (145 LOC): Contains production-ready archive streaming (`downloadGithubRepoArchive`) and file system writers (`writeZipToDirectoryHandle`), but `CloneModal` and `CloneScreen` rely on simulated delays.
5. **Screen Directory Fragmentation**:
   - Desktop screens are located in `src/features/desktop/screens/` except `src/screens/CloneScreen.tsx` and `src/screens/repodetails/PRsScreen.tsx`, which sit isolated in `src/screens/`.
6. **Linter & Compilation Status**: `npm run lint` (`tsc --noEmit`) and `compile_applet` compile with zero errors.

## Objective

- **Purpose**: Clean up orphaned root assets, reconcile fragmented screen folder structures, activate dormant filtering and download services, and polish UI elements to strict SaaS design standards without breaking existing functionality.
- **Problem**: Leftover build files (`bun.lock`, `dev-dist/` in git), misplaced desktop screen files (`src/screens/`), and dormant utilities (`sortRepos.ts`, `cloneService.ts`) increase cognitive overhead and leave features under-leveraged.
- **Business & Technical Value**: Reduces project bloat, improves developer velocity, enhances offline and online repository sorting/filtering, and ensures long-term codebase health.
- **Success Criteria**:
  - 0 unreferenced or dead utility files.
  - All desktop screens unified under `src/features/desktop/screens/`.
  - Full personal repository sorting (stars, forks, name, updated) and type filtering operational.
  - Real archive download progress hooked into clone workflows.
  - Strict `<= 150 LOC` maintained across 100% of `.ts` and `.tsx` files.
  - Zero TypeScript, lint, or runtime console errors.
- **Non-Goals**: No removal of working Git features, D3 visual graph logic, Monaco diff engines, or ZIP sync algorithms.

## Implementation Breakdown

### Phase 1: Project Root & Build Hygiene
- Add `dev-dist/` and `*.tsbuildinfo` to `.gitignore`.
- Remove orphaned `bun.lock`.
- Cleanly document or archive Cloudflare worker leftovers (`worker.ts`, `wrangler.toml`) so Express dev server remains the canonical runtime.

### Phase 2: Screen Structure Normalization
- Move `src/screens/CloneScreen.tsx` to `src/features/desktop/screens/DesktopCloneScreen.tsx`.
- Move `src/screens/repodetails/PRsScreen.tsx` to `src/features/desktop/screens/DesktopPRsView.tsx`.
- Create clean 1-line re-export facades at `src/screens/CloneScreen.tsx` and `src/screens/repodetails/PRsScreen.tsx` for 100% backwards compatibility.
- Update `DesktopRepoWorkspace.tsx` to import directly from normalized desktop screens.

### Phase 3: Service Activation & Feature Wiring
- **Repository Filter & Sort Integration**:
  - Connect `filterAndSortRepos` from `src/mobile/utils/sortRepos.ts` into `src/mobile/screens/repositories/useRepositoriesState.ts`.
  - Enable instant client-side filtering by query, repository type (public, private, forks, sources), and sorting by updated time, stars, forks, and repository name.
- **Clone & Archive Service Wiring**:
  - Wire `downloadGithubRepoArchive` from `src/features/clone/utils/cloneService.ts` into `CloneModal` and `DesktopCloneScreen` so real progress feedback (speed, percentage, downloaded bytes) streams during downloads.

### Phase 4: SaaS Visual & Accessibility Polish
- Audit all metadata badges to ensure strict compliance with Zero-Pill rules (unboxed text with `·` separators).
- Enforce `font-variant-numeric: tabular-nums` across all counters, additions/deletions (`+12/-2`), timestamps, and sizes.
- Verify 4.5:1 text contrast and touch target heights ($\ge 44\text{px}$ on mobile, $\ge 32\text{px}$ on desktop).

### Phase 5: Verification & Post-Task Audit
- Run `find src -type f \( -name "*.ts" -o -name "*.tsx" \) -exec wc -l {} + | awk '$1 > 150 { print }'` to prove 0 files exceed 150 LOC.
- Co-execute `compile_applet` and `lint_applet` together to verify 0 errors.
- Restart dev server via `restart_dev_server`, wait 10 seconds, and verify `HTTP 200 OK` on `http://localhost:3000`.
